题目：基于时间序列感知的GRUA-TD3强化学习控制算法

0  引言
    — 工程背景：TMD→ATMD 的需求，传统控制依赖精确模型的局限
    — DRL/TD3 在振动控制中的现有成果与"理想假设"困境
    — 多源时滞 + 采样抖动 → MDP 退化为 POMDP → MLP 失效
    — 本文提出 GRUA-TD3 的三项改进 + 主要结论一句话

1  TD3算法基础与POMDP问题分析
    1.1  TD3算法原理
         — Actor-Critic 架构回顾
         — 三大核心机制：双 Critic 取 min、延迟策略更新、目标策略平滑
         — 公式控制在 3–4 个，突出 TD3 为何适用于连续动作空间
    1.2  时滞与采样不确定性的理论建模
         — 总时滞建模：$\tau = \tau_{\mathrm{sensor}} + \tau_{\mathrm{compute}} + \tau_{\mathrm{actuator}}$
         — 采样抖动：$t_{k+1} = t_k + \Delta t + \delta_k$
         — MDP → POMDP 的退化路径
         — MLP 全连接网络在 POMDP 下的信息缺失分析

2  基于时间序列感知的GRUA-TD3控制器设计
    2.1  总体框架
         — 框架示意图 + 三项改进概述
         — 改进一：GRU 层提取时序依赖
         — 改进二：时间增强状态显式感知时间维度
         — 改进三：自注意力机制动态加权关键时间步
    2.2  GRU时序特征提取
         — GRU vs LSTM vs RNN 的选型分析
         — 更新门 $z_t$、重置门 $r_t$ 的计算公式（见正文式(7)–(10)）
         — GRU 层置于 Actor/Critic 前端的设计
         — 历史序列 → 隐藏状态 → 预测未来序列的近似预测器
    2.3  时间增强状态构造
         — $\mathbf{S}_t = [\tilde{\mathbf{X}}, \Delta t_{\mathrm{last}}, \tau_{\mathrm{delay}}]$
         — 时间信息显式并入状态空间的动机与效果
    2.4  自注意力加权汇聚
         — 自注意力原理简述
         — 隐状态拼接：历史隐状态 + 预测隐状态 → $\mathcal{H}_t \in \mathbb{R}^{T \times d_h}$
         — 打分函数 $e_j = \mathbf{w}_a^{\top} \mathbf{h}_j + b_a$ → Softmax 归一化 → $\alpha_i$
         — 加权汇聚：$\bar{\mathbf{S}}_t = \sum_{i=1}^{T} \alpha_i \mathbf{S}_i$
    2.5  奖励函数与训练策略
         — 分段平滑奖励：容差阈值 $\varepsilon$ 内的正向奖励 + 超限对数惩罚（见正文式(15)–(16)）
         — 动作惩罚项：$r_{\mathrm{act}} = -|A_t|/(4 A_{\max})$
         — 训练中随机注入 $\Delta t$ 与 $\tau_{\mathrm{delay}}$ 的机制
         — 梯度裁剪防止 GRU 循环结构梯度不稳定：$\|\nabla_{\theta}\|_2 \leq c$

3  系统建模与仿真实验
    3.1  主结构-ATMD系统动力学建模
         — 二自由度物理模型示意图
         — 牛顿运动方程 $\to$ 连续时间状态空间方程 $\dot{\mathbf{X}} = \mathbf{AX} + \mathbf{B}u + \mathbf{E}z + \mathbf{G}F$
         — 系统参数表（$m, M, k_m, k_M, c_m, c_M$ 等）
         — 固有频率分析（主结构 $\approx 4\,\mathrm{Hz}$，吸振器 $\approx 3.8\,\mathrm{Hz}$）
    3.2  非理想仿真环境构建与实验设置
         — 理想环境：固定步长 $\Delta t = 0.001\,\mathrm{s}$，无时滞
         — 非理想环境：随机时滞 $\mathcal{N}(\mu, \sigma)$ + 变步长采样

         — 超参数汇总表（学习率、GRU 隐藏单元、序列长度、梯度裁剪等）
    3.3  训练奖励曲线对比
         — 理想环境 vs 非理想环境的奖励曲线
         — TD3 vs GRUA-TD3 收敛速度与最终奖励对比
    3.4  自由振动工况（初始位移 $x_2 = 0.006\,\mathrm{m}$）
         — 理想环境：四种控制器响应对比

4  结论
    — 三点结论：
      (1) 标准 TD3 用于无模型振动控制的可行性验证
      (2) GRUA-TD3 三项改进（GRU + 时间增强状态 + 自注意力）的有效性
      (3) 非理想环境下 GRUA-TD3 鲁棒性显著优于 PID 与标准 TD3
    — 两点展望：
      (1) 部署到实际振动控制实验平台，验证真实物理链路效果
      (2) 向非线性多自由度系统扩展，探索 PPO/元强化学习等框架
